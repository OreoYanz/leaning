### 檢查項目說明

1. `document.documentElement.scrollWidth <= clientWidth`（無水平溢出）
2. 頂部「回首頁」「靜音」按鈕在可視範圍內且可點
3. 拼音火箭：注音選項 ≥ 約 40px、格子可見、拖曳／點選可放上火箭
4. 拖曳中不應捲動整頁；`pointercancel` 後可再操作
5. 縮小／拉高視窗（模擬 Safari 工具列）後操作區仍可用
